# רוד ראן (Road Run)

**לשחק עכשיו:** https://sgolan20.github.io/road-run/

משחק ריצה אינסופית תלת-ממדי בדפדפן. הילד צייר גרפיטי, השוטר רודף אחריו ברחובות,
ובדרך אוספים פנקייקים, קופצים מעל מכשולים ועוברים בין נתיבים.

המצלמה אלכסונית (כ-45 מעלות), מאחורי השחקן ומימינו: הילד רץ קדימה לתוך המסך,
השוטר רודף אחריו בין המצלמה לילד, והמכשולים והפנקייקים מגיעים מהאופק שלפנים.

## הרצה

אין תהליך בנייה. Three.js נמצא מקומית ב-`vendor/`, אז המשחק עובד גם בלי אינטרנט.

```bash
python3 -m http.server 8080
```

ואז לגלוש אל http://localhost:8080 (אפשר גם לפתוח את `index.html` ישירות).

## שליטה

- רווח / חץ למעלה / W: קפיצה (יש קפיצה כפולה)
- חץ שמאלה/ימינה או A/D: מעבר נתיב (שלושה נתיבים)
- מובייל: החלקה ימינה/שמאלה = מעבר נתיב, החלקה למעלה או נגיעה = קפיצה, החלקה למטה או נגיעה כפולה = פלוץ
- לחיצה כפולה על המסך / F / חץ למטה: פלוץ ענק (רק אחרי פנקייק רקוב)
- Escape: חזרה לתפריט

## פנקייקים מיוחדים

כל 250 מטר מופיע פנקייק מיוחד באחד הנתיבים:

- **פנקייק מוזהב** נותן מגן. אם השוטר תופס את הילד כשיש מגן, המגן מתנפץ, השוטר נזרק אחורה והריצה ממשיכה.
- **פנקייק רקוב** טוען פלוץ ענק. לחיצה כפולה על המסך (או F) משחררת אותו ומעיפה את השוטר אחורה.

## סאונד

אפקטי הסאונד בתיקיית `sounds/` הופקו ב-ElevenLabs (מודל `eleven_text_to_sound_v2`),
קוצרו ונורמלו עם ffmpeg. הם נטענים מראש ומנוגנים דרך WebAudio.
אם קובץ לא נטען (למשל פתיחת `index.html` מהדיסק בלי שרת), המשחק חוזר אוטומטית
לצפצופים סינתטיים, כך שתמיד יש סאונד.

## מבנה

- `index.html` - המסכים (תפריט, HUD, סיום)
- `style.css` - עיצוב הממשק
- `src/game.js` - כל לוגיקת המשחק, בניית המודלים והסצנה
- `sounds/` - אפקטי הסאונד
- `vendor/three.min.js` - Three.js r128
- `2d/` - הגרסה הדו-ממדית המקורית (לעיון)

## הערה על הגרפיקה

כל המודלים (דמויות, מכשולים, פנקייק, בניינים) בנויים כרגע מצורות בסיסיות בקוד
(`buildCharacter`, `OBSTACLE_TYPES[*].build`, `buildPancake`, `placeBuilding`).
כשיהיה עיצוב סופי, מחליפים את הפונקציות האלה בטעינת מודלים (GLTF) בלי לגעת בלוגיקה.

## דיבוג

בקונסול של הדפדפן זמין `window.RoadRun` עם `state`, `jump()`, `moveLane(dir)`, `startGame()`.
